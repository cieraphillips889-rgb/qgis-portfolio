# Baltimore Neighborhood Map

## Project Overview
This project visualizes neighborhood boundaries in Baltimore, Maryland using QGIS and publicly available GIS data from the Baltimore Open Data Portal.

The purpose of this project is to demonstrate beginner-level geospatial analysis skills, including loading vector data, styling polygon layers, labeling features, and exporting a professional map layout.

---

## Skills Demonstrated
- Loading GeoJSON vector data into QGIS
- Polygon symbology and boundary styling
- Feature labeling
- Print Layout creation
- Exporting maps to PNG and PDF
- Organizing GIS project files

---

## Tools Used
- QGIS 3.44 (LTR)
- GeoJSON
- GitHub

---

## Data Source
- Baltimore Open Data Portal: https://data.baltimorecity.gov

---

## Project Files
- `baltimore-neighborhood-map.qgz` – QGIS project file
- `data/Neighborhoods.geojson` – Neighborhood boundary dataset
- `exports/baltimore-neighborhood-map.png` – Final exported map image
- `exports/baltimore-neighborhood-map.pdf` – Final exported PDF map (optional)
