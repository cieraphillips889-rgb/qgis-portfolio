# Baltimore Neighborhood Map

## Project Overview
This project visualizes neighborhood boundaries in Baltimore using QGIS and public GIS data.

## Skills Demonstrated
- Vector layer loading
- Polygon styling
- Map labeling
- Print layout design
- Image and PDF export

## Tools Used
- QGIS
- GeoJSON
- Baltimore Open Data

## Data Source
Baltimore Open Data Portal
